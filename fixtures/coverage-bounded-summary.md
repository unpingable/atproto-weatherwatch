# Bounded observation coverage conformance vector

[`coverage-bounded-summary.json`](coverage-bounded-summary.json) is an actual
synthetic report generated by
`tests/test_interval_coverage.py::test_report_discloses_partial_piece_uncertainty_replay_and_gaps`.
The producer is `weatherwatch.report.generate_report`. It contains no production
observations. Its exact SHA-256 is
`0bee480476e092e2d3cc4bd4f3738344ad94b40229d90a1b3a416f779b42b559`.

The five-minute physical interval has six recorded health rows plus one
unobserved bucket. Recorded durations sum to 320 seconds. Full-width evidence
resolves one shared bucket; the other shared bucket contains two partial
40-second pieces whose exact overlap is unknown. The duration union is
220–240 seconds, both exact scalars are null, and `coverage_status` is
`bounded`. A replay seam, gap ledger and quality metadata remain present.

Weather's producer regression compares `schema`, `interval`, `windows`,
`metrics`, `total_events` and `runs` against this frozen output. Its literal
assertions also pin the coverage result independently. `generated_at`, the
random `store` identity/creation metadata and clock-dependent `freshness`
values are excluded from comparison; they are unrelated to duration overlap.
Run wall-clock timestamps are fixed synthetic inputs and remain compared.

The consuming `atproto-facts-api` adapter uses the identical fixture bytes for
its real conditions and metrics transforms. Each consumer owns its test and
pins the producer revision it reviewed. A golden change requires checking both
sides against [the public interval contract](../docs/PUBLIC-ARTIFACTS.md#interval-time-coverage);
a hash assertion alone is not a conformance test.
